# Contributor Covenant Code of Conduct

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

Examples of unacceptable behavior include harassment, trolling, personal attacks, publishing another person's private information, and sharing private prompts, credentials, files, or logs without explicit permission.

Project maintainers may remove or reject contributions and participation that violate these standards. Report conduct issues privately to the maintainers through the contact method listed on the published GitHub repository.

This text is adapted from Contributor Covenant 2.1: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
